# Свои — GitHub Pages

Готовое статическое веб-приложение. Сборка, npm, Python и ключи API для публикации не нужны.

## Публикация

1. Создайте публичный репозиторий на GitHub.
2. Распакуйте архив. Загрузите его содержимое в корень ветки main через Add file → Upload files или Git. Загружайте файлы и папки, а не сам ZIP. Файл index.html должен находиться в корне репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Source: Deploy from a branch.
5. Выберите ветку main и папку /(root), нажмите Save.
6. Дождитесь завершения публикации. Ссылка появится в Settings → Pages: https://USERNAME.github.io/REPOSITORY/.

При обновлении загрузите изменённые файлы в ту же ветку. После публикации обновите страницу браузера.

В архив включён пустой .nojekyll для статической публикации без Jekyll. В Finder скрытые файлы отображаются сочетанием Cmd+Shift+.; при загрузке через веб-интерфейс убедитесь, что он тоже добавлен.

Инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Возможности

Карта Тюмени, фотометки ям и мусора, лайки, комментарии, поиск, фильтры, добавление проблем с фото и выбором точки, команды, волонтёрское событие, фотоотчёты до/после, XP, уровни, профиль и лидерборд за неделю и всё время.

## Данные демки

Все стартовые проблемы, адресные привязки, лайки, участники, команды и события — демонстрационные. Профиль, новые отметки, фотографии и прогресс сохраняются только в localStorage браузера посетителя. Общего сервера, аккаунтов, синхронизации между людьми и модерации фото нет. На новом домене сохранения начнутся заново; локальный прогресс с localhost автоматически не переносится.

XP начисляется локально после загрузки двух разных фото: 150 за демонстрационное событие и 75 за уборку отметки с мусором. Повторная награда за ту же задачу не начисляется. Лидерборд пересчитывает позицию посетителя среди демонстрационных участников.

Для картографических тайлов нужен интернет. Если тайлы недоступны, используется условная схема Тюмени, не предназначенная для навигации. Шрифт загружается из Google Fonts с системным запасным шрифтом.
